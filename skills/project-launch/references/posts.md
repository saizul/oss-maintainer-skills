# Post templates

The script output follows these shapes. Replace every bracketed part with the
author's real words.

## Show HN

Title (80 characters max):

```
Show HN: dbsnap – Consistent Postgres and MySQL snapshots to S3 in one command
```

First comment:

```
Hi HN, I built dbsnap after [the problem, one or two sentences].

[What it does in plain words. How it works: the interesting technical bit.]

[What it does not do yet / known limitations.]

It's open source (MIT): [repo URL]. I'd love feedback on [one specific question].
```

Good titles describe the thing. Avoid: "the best", "blazing fast", "revolutionary",
exclamation marks, emoji, and questions as titles.

## Reddit

```
Title: I built dbsnap, a CLI that snapshots Postgres and MySQL to S3 with one config file

What it is: [one paragraph]
Why I made it: [the itch]
What's different: [2-3 concrete points vs. what people already use]
Status: [alpha/beta/stable, what is missing]

Repo: [URL]. Feedback and contributions welcome; happy to answer questions.
```

## dev.to article outline

1. Hook: the problem as a short story (3-5 sentences)
2. What the project does (the pitch, one diagram or GIF)
3. Quick start (real commands)
4. How it works (the interesting part, with code)
5. Trade-offs and what is next (link good first issues)
6. Call to action: try it, star it if useful, contribute
